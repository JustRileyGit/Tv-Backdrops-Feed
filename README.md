# Weekly TV Backdrops

The top 25 trending titles on TMDB each week, as 4K backdrops with the title's logo, updated every Saturday.
A feed for the **Overflight** plugin for Projectivy Launcher on Android TV.

**Last updated: 28 November 2026** (25 backdrops)

## Use it on your TV

1. Install **Overflight (Projectivy Plugin)** on your TV. It needs Projectivy Premium.
2. In Projectivy, open Settings, then Appearance, then Wallpaper, and choose **Overflight**.
3. Open the Overflight settings and set **Media source** to this link:

```
https://raw.githubusercontent.com/JustRileyGit/tv-backdrops-feed/main/feed.json
```

4. Set **Media source cache duration** to `24` hours.
5. Tick **Fallback to lower quality if not available**. The 4K and HDR options are for videos only, so as long as Fallback is ticked it will work.
6. Check that **Found wallpapers count** shows 25.
